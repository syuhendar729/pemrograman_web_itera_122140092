════════════════════════════════════════════════════════════════════════════════
                         DESIGN PATTERNS & PRINCIPLES USED
════════════════════════════════════════════════════════════════════════════════

1. ABSTRACT CLASS PATTERN
   - LibraryItem sebagai abstract base class
   - Memaksa implementasi method di subclass

2. TEMPLATE METHOD PATTERN
   - Abstract methods sebagai template
   - Subclass menyediakan implementasi spesifik

3. ENCAPSULATION
   - Private attributes: __available, __items, __name
   - Protected attributes: _id, _title, _author, dll
   - Public interface melalui properties dan methods

4. POLYMORPHISM
   - Method overriding: get_info(), calculate_late_fee()
   - Duck typing: Library dapat bekerja dengan semua LibraryItem

5. COMPOSITION
   - Library memiliki koleksi LibraryItem
   - Relationship 1:N (one-to-many)

                         CARA MENGGUNAKAN DIAGRAM INI
════════════════════════════════════════════════════════════════════════════════

Untuk Draw.io / Diagrams.net:
1. Buka draw.io
2. Pilih template "UML Class Diagram"
3. Buat 4 kotak untuk masing-masing class
4. Tambahkan kompartemen untuk:
   - Nama class (bagian atas)
   - Attributes (bagian tengah)
   - Methods (bagian bawah)
5. Hubungkan dengan:
   - Panah inheritance (segitiga terbuka) dari Book/Magazine ke LibraryItem
   - Panah composition (diamond) dari Library ke LibraryItem
6. Gunakan stereotypes:
   - <<abstract>> untuk LibraryItem
   - + untuk public
   - # untuk protected
   - - untuk private

Untuk PlantUML:
Lihat file class_diagram.puml untuk syntax PlantUML

Untuk Lucidchart:
1. Pilih UML Class Diagram template
2. Drag-drop class shapes
3. Edit kompartemen sesuai dengan informasi di atas
4. Hubungkan dengan relationship lines


════════════════════════════════════════════════════════════════════════════════
                                  VISIBILITY
════════════════════════════════════════════════════════════════════════════════

+ Public       : Dapat diakses dari mana saja
# Protected    : Dapat diakses dari class itu sendiri dan subclass (single _)
- Private      : Hanya dapat diakses dari class itu sendiri (double __)
